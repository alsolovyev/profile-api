    Digital Profile API

    Backend цифровой визитки разработчика. API предоставляет профиль, навыки, опыт работы, проекты и профессиональные ссылки через GraphQL. Данные хранятся в PostgreSQL и доступны через Prisma.

    NestJSGraphQLPrismaPostgreSQL
    PROFILE APIonline

      profile { name skills projects }
    }

    • Node.js
    • TypeScript

    02

    Запуск через Docker

    Рекомендуемый способ запуска из чистого checkout. Compose поднимает PostgreSQL и API, затем генерирует Prisma Client, применяет миграции, заполняет базу начальными данными и запускает Nest в режиме watch.

    TERMINAL
    cp .env.example .env
make start

    По умолчанию API доступно по адресу http://localhost:3000. GraphQL endpoint и интерактивный интерфейс GraphiQL находятся на http://localhost:3000/graphql, HTTP-проверка состояния — на http://localhost:3000/health.

    Полезные команды

    MAKE
    make logs       # следить за логами контейнеров
make status     # посмотреть состояние сервисов Compose
make stop       # остановить сервисы, сохранив данные БД
make reset      # остановить сервисы и удалить локальный volume БД
    03

    Запуск без Docker

    Укажите параметры PostgreSQL в .env (образец находится в .env.example), затем выполните:

    TERMINAL
    npm install
npm run db:generate
npm run db:migrate:deploy
npm run db:seed
npm run start:dev

    Чтобы создать миграцию при изменении схемы:

    TERMINAL
    npm run db:migrate:dev -- --name describe_change
    04

    GraphQL API

    Откройте /graphql в браузере. Запрос профиля:

    GRAPHQL · PROFILE
    query Profile {
  profile {
    id
    name
    description
    links { label url }
    skills { name }
    experiences {
      company
      position
      startDate
      endDate
      achievements
    }
    projects { name description url }
  }
}

    Для проверки состояния приложения:

    GRAPHQL · HEALTH
    query Health {
  health {
    status
    timestamp
    uptime
    version
    database
  }
}

    Также можно обратиться к HTTP endpoint:

    HTTP
    curl http://localhost:3000/health

    Инициализация данных

    Seed-скрипт находится в src/prisma/prisma.seed.ts. Он создает один профиль и связанные с ним профессиональные ссылки, навыки, места работы и проекты. Для повторяемости используется постоянный UUID.

    07

    Конфигурация

    Скопируйте .env.example в .env. Обязательные переменные PostgreSQL: POSTGRES_USER, POSTGRES_PASSWORD, POSTGRES_HOST, POSTGRES_PORT и POSTGRES_DB. Для PORT задано значение по умолчанию 3000.

    В Compose host и port базы данных внутри контейнеров переопределяются. Для production задайте надежный пароль и храните переменные окружения в настройках или секретах платформы.

    Оптимизация проекта

    Сокращение обращений к базе. Профиль и его ссылки, навыки, опыт работы и проекты загружаются отдельными вызовами репозитория. При росте нагрузки можно измерить число запросов к PostgreSQL и рассмотреть объединенную загрузку связанных данных.

    Кэширование запросов. Результаты часто используемых GraphQL-запросов, например профиля, можно кэшировать на короткое время (TTL). После изменения данных соответствующий кэш нужно сбрасывать. В основной ветке кэширование пока не подключено, но в другой ветке реализован простой кэш в памяти процесса (in-memory cache). См. Pull Request #1.
